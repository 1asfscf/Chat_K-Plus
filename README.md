저희의 새로운 연구작품 Chat K Plus에 대해 설명해 드리고자 합니다.

1. Chat K Plus 개요

Chat K Plus는 기존 저희의 프로젝트였던 Chat GOT의 정체성 안에서, 독립적인 노선을 통해 새롭게 탄생하게 된 모델입니다.

Chat GOT라는 이름이 지닌 방향성은 유지하되, 그 안에서 한층 더 정제되고 고도화된 응답 완성도를 목표로 하여 Chat K Plus 라는 새로운 명칭으로 여러분께 선보이게 되었습니다.

현재 Chat K Plus는 초기 모델이 준비 단계에 있으며, 기존 Chat GOT의 기반 위에 독자적인 설계를 더해 개발 중에 있습니다.

2. 준비 중인 모델 (Model in preparation)

2.1. KRL(Knowledge Refined Language) 기반

해당 모델은 KRL(Knowledge Refined Language)을 기반으로 설계되고 있습니다.

KRL이란?
기존 AI의 LLM들이 가진 주요 답변 스타일 중, 검증된 표현 체계만을 참고하여 답변을 구성하는 특수한 기반 구조입니다.

2.2. 검증 중심 학습 방식 (Verification-driven learning)

일반적인 LLM이 방대한 데이터를 학습하는 것과 달리,
KRL 기반 모델은 데이터의 양보다 응답의 신뢰도와 완성도 그 자체에 집중하여 답변을 생성하는 방식으로 동작합니다.

📌 즉, “얼마나 많이 아는가”가 아닌 “얼마나 정확하게 전달하는가” 의 신뢰도와 완성도에 집중한 모델입니다.

2.3. 모델 동작 방식

해당 모델의 주요 시스템은 다음과 같습니다.

KRL 기반을 따름

데이터베이스 v3를 비롯한 여러 버전의 데이터베이스를 기반으로 답변을 구성

각 데이터베이스 버전에 따른 업데이트 및 향후 패치 등을 통해 지속적으로 개선

종합하면,
이 모델은 KRL 기반을 따르며, v3 외 여러 버전의 데이터베이스를 중심으로 답변을 구성하고, 해당 베이스에 따른 업데이트와 패치가 지속 적용되는 방식이라고 이해하시면 됩니다.

3. 모델 라인업

이번 스텔스 테스트를 통해 공개되는 모델은 총 3종입니다. 모든 모델은 API 기반이 아닌, JS 혁신을 통한 데이터베이스 기반으로 동작합니다.

(NEW) 1. Chat K-Plus Basic
강력하지만 기본 모델로서, 표 및 그래프 생성은 지원하지 않습니다. 추론 모드는 3개 모델 모두 동등하게 지원합니다.

(NEW) 2. Chat K-Plus Pro
표 및 그래프 생성을 지원합니다. 추론 모드 비활성화 시에도 표 및 그래프 생성은 가능하지만, 더 자세한 분석은 불가능합니다.

(NEW) 3. Chat K-Plus Ultra
데이터와 능력이 한층 더 향상된 최상위 모델입니다. 표 및 그래프 생성을 지원하며, Pro와 마찬가지로 추론 모드 비활성화 시에는 표 및 그래프 생성은 가능하지만 더 자세한 분석은 불가능합니다.

전 모델 공통으로 표 및 그래프 생성은 지원하지만 일부 미숙한 부분이 있을 수 있습니다. 그러나 API 등급은 어느 정도 수준에 도달한 것으로 평가되고 있으며, 추론 모드 역시 API 등급 기준으로 어느 정도 구현에 성공한 상태입니다.

다만, Ultra 모델이라고 할지라도, 데이터베이스의 한계로 아직 데이터 및 생각 기능에 원활하지 않은 버그가 있을 수 있습니다.

4. 향후 오픈 테스트 관련 안내

향후 오픈 베타 테스트에서는 Ultra 모델의 추론 모드 비활성화 버전이 별도로 공개될 예정입니다. 이 버전은 추론 모드 자체가 비활성화된 상태로 제공되며, 지금보다 지식이 업그레이드된 버전으로 이용하실 수 있습니다.

반면, 추론 모드 활성화 업그레이드 모델, 마스터 라이트 버전은 v4 지식 베이스를 기반으로 더 깊은 기능과 더 포괄적인 지식을 제공할 예정이며, 이 모델은 빠르면 7월 중으로 공개될 예정입니다.

단, 마스터 라이트 버전은 오픈 베타라 할지라도 모두가 자유롭게 이용할 수 있는 것은 아닙니다. 팀 이메일 또는 개발팀에게 우선 접근 코드를 부여받은 사용자에 한하여 이용 가능하도록 할 예정입니다.
